[# NEMEC_PMA_01

React Native + Expo project (JavaScript).

## Scripts
- `npm start` / `npx expo start`: Start Expo development server
- `npm run android` / `npx expo start --android`: Run on Android
- `npm run ios` / `npx expo start --ios`: Run on iOS
- `npm run web` / `npx expo start --web`: Run on web

## Files
- `App.js`: Main blank React Native application component
- `PMA.js`: PMA assignment component
- `index.js`: Registers `App` with Ex]()po
- `app.json`: Expo app manifest
